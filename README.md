# 🚴 GlovoRunBike

Proyecto interactivo desarrollado en **Unity** para la asignatura de **Gráficos y Multimedia** en la Universidad Jaume I (UJI).

## 📝 Descripción
**GlovoRunBike** es un videojuego/aplicación en 3D enfocado en mecánicas de conducción y simulación de repartos en entorno urbano. El proyecto implementa modelos 3D, físicas de vehículos, gestión de escenas y animaciones utilizando la suite de desarrollo Unity.

## 🛠️ Tecnologías utilizadas
* **Motor gráfico:** Unity
* **Lenguaje:** C#
* **Control de versiones:** Git & GitHub
